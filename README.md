# MasterTyres - финальный сайт

Финальная версия сайта собрана по утвержденному demo-концепту и использует реальные контакты MasterTyres.

## Запуск

```bash
npm run dev
```

Откройте `http://127.0.0.1:4173`.

## Проверка и сборка

```bash
npm run check
npm run build
```

`npm run standalone` обновит файл `MasterTyres-final.html`. Он полностью автономный: стили, скрипты и изображения встроены в один HTML-файл.
